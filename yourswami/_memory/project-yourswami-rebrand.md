**SITE-WIDE CSS BUG FIXED (2026-08-23):** `globals.css` had an **unlayered** `* { margin:0; padding:0 }`. Tailwind v4 puts utilities in `@layer utilities`, and unlayered CSS beats layered CSS regardless of specificity, so **every `p-*`, `m-*` and `space-y-*` computed to 0 site-wide** (a fresh `<div class="p-4">` measured 0px). That is why every page looked "stuffed". Fixed by wrapping the reset in `@layer base`. Related: `.btn-glow` is defined after the Tailwind import and sets font-size and padding, so `text-sm` never applies to it; use inline styles there.
